# 🗺️ Nodu — Mapa de Conocimiento del Proyecto (MOC / Obsidian Index)

Bienvenido a la bóveda de conocimiento estructurada de **Nodu**. Este sistema de notas interconectadas (estilo Obsidian) mantiene la verdad arquitectónica, pedagógica y de diseño para que cualquier desarrollador o agente de IA comprenda el sistema sin pérdida de contexto.

---

## 📌 Núcleo de Producto y Filosofía
- [[PRODUCT]]: Visión, propuesta de valor, público objetivo y pedagogía del error.
- [[UX_GUIDELINES]]: Principios de experiencia, 22 pantallas mapeadas y ergonomía táctil de código.
- [[DESIGN_SYSTEM]]: Tokens CSS, paleta *Neo-Terminal Friendly*, componentes e iconografía SVG propia.
- [[GAMIFICATION]]: Mecánicas de hábito, cálculo de XP, niveles, rachas protegidas (*Streak Freeze*) y medallas.

---

## ⚙️ Arquitectura Técnica y Local-First
- [[ARCHITECTURE]]: Aislamiento de código seguro (Web Workers), comparativa técnica y rendimiento.
- [[COURSE_SCHEMA]]: Contratos de tipado TypeScript para unidades, niveles y los 10 tipos de ejercicios.
- [[LEARNING_ENGINE]]: Máquina de estados de lección y validadores puros deterministas.
- [[LESSON_PLAYER]]: Arquitectura y flujo del reproductor inmersivo de lecciones polimórfico.
- [[AUDIO_FEEDBACK]]: Síntesis sonora nativa con Web Audio API y micro-recompensas.
- [[CERTIFICATES]]: Generación de certificados vectoriales PDF en cliente con firma criptográfica SHA-256.
- [[OFFLINE_STORAGE]]: Persistencia IndexedDB reactiva con Dexie.js, Service Worker PWA y respaldo JSON.
